## 🌐 Market Size & Industry Dynamics

The global Architecture, Engineering, and Construction (AEC) Project Management software market size is estimated at **~$9.2 Billion USD**, projected to reach **~$15.8 Billion USD by 2030** (growing at a CAGR of ~9.5%). 

The A/E practice management software sector is **highly fragmented**. While legacy giants like Deltek hold strong market share among large enterprise consultancies, the mid-market and small-firm segments are heavily divided across dozens of specialized SaaS tools (e.g., Monograph, BQE CORE, Factor AE) and general professional services automation (PSA) tools. There is currently no single "winner-take-all" dominant platform across all firm sizes.

## 💻 Open-Source GitHub Projects

While purpose-built open-source A/E practice platforms are still emerging, below are leading open-source project management, ERP, timesheet, and AEC data platforms sorted by **GitHub Stars_Count** (descending).

- **[MakePlane / Plane](https://github.com/makeplane/plane)** <a href="https://github.com/makeplane/plane/stargazers"><img src="https://img.shields.io/github/stars/makeplane/plane?style=social&color=white" alt="Plane Stars"/></a>  
  🚀 Modern, self-hosted open-source project tracking and workspace tool—ideal alternative to Jira/Asana for managing design sprints, task deliverables, and team issues.

- **[Odoo](https://github.com/odoo/odoo)** <a href="https://github.com/odoo/odoo/stargazers"><img src="https://img.shields.io/github/stars/odoo/odoo?style=social&color=white" alt="Odoo Stars"/></a>  
  📦 Extensible open-source ERP suite featuring modular project management, timesheets, invoicing, and custom billing rules adaptable for architectural firms.

- **[ERPNext](https://github.com/frappe/erpnext)** <a href="https://github.com/frappe/erpnext/stargazers"><img src="https://img.shields.io/github/stars/frappe/erpnext?style=social&color=white" alt="ERPNext Stars"/></a>  
  💼 Full-featured open-source ERP system offering project budgeting, time logs, client portals, and job costing modules suitable for A/E consultancy workflows.

- **[OpenProject](https://github.com/opf/openproject)** <a href="https://github.com/opf/openproject/stargazers"><img src="https://img.shields.io/github/stars/opf/openproject?style=social&color=white" alt="OpenProject Stars"/></a>  
  📅 Enterprise-grade open-source project management software supporting Gantt charts, phase timelines, resource loading, and cost tracking.

- **[Leantime](https://github.com/leantime/leantime)** <a href="https://github.com/leantime/leantime/stargazers"><img src="https://img.shields.io/github/stars/leantime/leantime?style=social&color=white" alt="Leantime Stars"/></a>  
  💡 Open-source strategic project management system combining ideation, phase milestone planning, and task execution for design teams.

- **[Vikunja](https://github.com/go-vikunja/vikunja)** <a href="https://github.com/go-vikunja/vikunja/stargazers"><img src="https://img.shields.io/github/stars/go-vikunja/vikunja?style=social&color=white" alt="Vikunja Stars"/></a>  
  ✅ Self-hosted, intuitive task management application with kanban boards, Gantt charts, and team collaboration features.

- **[Kimai](https://github.com/kimai/kimai)** <a href="https://github.com/kimai/kimai/stargazers"><img src="https://img.shields.io/github/stars/kimai/kimai?style=social&color=white" alt="Kimai Stars"/></a>  
  ⏱️ Free open-source time-tracking and invoicing application designed for tracking billable hours across multiple client projects and phases.

- **[Taiga](https://github.com/taigaio/taiga-back)** <a href="https://github.com/taigaio/taiga-back/stargazers"><img src="https://img.shields.io/github/stars/taigaio/taiga-back?style=social&color=white" alt="Taiga Stars"/></a>  
  🎨 Agile project management platform for cross-functional teams needing clean task backlogs and board workflows.

- **[Speckle Server](https://github.com/specklesystems/speckle-server)** <a href="https://github.com/specklesystems/speckle-server/stargazers"><img src="https://img.shields.io/github/stars/specklesystems/speckle-server?style=social&color=white" alt="Speckle Stars"/></a>  
  🏗️ The open-source data platform for 3D AEC workflows—connects CAD/BIM models (Revit, Rhino, AutoCAD) directly to project collaboration pipelines.

- **[OpenBooks](https://github.com/braedonsaunders/openbooks)** — Open-source books / ERP with construction-friendly accounting for A/E and contractor firms.
